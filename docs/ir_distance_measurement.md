# 红外距离实测

此采样程序只订阅距离反馈，不发送底盘、舵机、机械臂、夹爪或 LED 命令。
它与抓放 demo 共用进程锁，避免同时建立两个 SDK 控制连接。

用尺子量测传感器测距窗口前表面到目标表面的距离。网球应以球中部正对窗口，
不要按球心距离或夹爪前缘距离标记；手、尺子及邻近物体不应挡住测距方向。
摆好并保持不动后，再开始一组采样：

```bash
cd /home/robot/projects/3-LEARN
bash scripts/run_ir_distance_ubuntu.sh --seconds 8 --label tennis-100mm --reference-mm 100
```

依次用 `100`、`50`、`30`、`20`、`40` mm 测试；每次都重新尺量，并同步更改标签及
`--reference-mm`。之后换水瓶重复；不能直接把网球的偏差用于透明水瓶。
`--reference-mm` 只记录人工量测值，不会校准、修正或影响传感器读数。

每秒显示当前配置端口的统计值，以及四个端口的最新原始读数。
记录保存在 `work/ir-distance/<时间戳>/samples.jsonl` 和 `summary.json`，包含各端口的
样本数、正数且不大于 10000 mm 的读数统计、配置阈值内样本数及最长连续次数。
旧版采样日志中的 `within_30mm_samples` 等字段仍指30 mm；新版在日志中明确记录所用阈值。
这些数值检查不能证明测量准确，也不能替代实际距离和目标摆放的核对。

3 cm 抓取触发是否可用，要同时看目标真的在 3 cm 时能否连续触发、较远距离是否会
误触发、重复摆放是否稳定，以及网球和水瓶能否各自满足条件。主程序阈值目前保持
20 mm（原始读数），采样程序不会自动修改配置。
